# DH-01 — Architecture Views

Este directorio contiene las vistas arquitectónicas del Academic Advising Case Management System.

Las vistas permiten comprender los límites del sistema, su estructura interna, las responsabilidades de sus componentes y su distribución en el entorno de ejecución.

## Índice de vistas

| ID | Vista | Documento |
|---|---|---|
| V-CTX | System Context | [System Context View](system-context.md) |
| V-CONT | Container View | [Container View](container-view.md) |
| V-COMP | Component View | [Component View](component-view.md) |
| V-DEP | Deployment View | [Deployment View](deployment-view.md) |

Las vistas utilizan diagramas Mermaid editables y mantienen consistencia con los requisitos y decisiones arquitectónicas de DH-01.
